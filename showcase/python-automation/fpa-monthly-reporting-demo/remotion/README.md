# FP&A Monthly Reporting — Raw Data to Final Report

This project is the editable source for the recruiter-facing video at
`../assets/fpa-monthly-reporting-remotion.mp4`.

## Creative direction

The 82-second film presents the real public-safe automation journey through a cinematic product-demo language:

1. Open inside the captured synthetic raw workbook.
2. Launch the real Python workflow through a public-safe runner.
3. Show all four live processing stages and management signals.
4. Reveal the standardized data, variance workbook, and reconciliation controls.
5. Open the generated `.docx` and hold on its executive readout.
6. Pull back to the report actions, owners, evidence, and Finance review boundary.
7. Close on the controlled outcome: raw data in, management report out.

The figures are synthetic and illustrative. They are not measured business impact.

## Commands

```powershell
npm install
npm run score
npm run lint
npm run dev
npm run render
npm run poster
```

`remotion.config.ts` points the Remotion public directory to the case-owned `../assets/` folder. The composition
uses the privacy-audited `recorded-process-source.mp4` capture and local Remotion sound effects. The deterministic
procedural score is generated by `scripts/generate-process-score.mjs`.

## Editable structure

- `src/workflow/` contains one React component per scene plus the shared workflow shell and management-report view.
- `src/Composition.tsx` owns scene timing, crossfades, score, sound cues, and scene registration.
- `scripts/generate-process-score.mjs` creates the 82-second PCM score.
- The main composition ID is `FpaAutomationDemo`.
